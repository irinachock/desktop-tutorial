# Роль: repo (хозяин репозитория)

## Задачи
- Ветки и PR: мёржить в `main` только после «ок» от tester; следить за конфликтами.
- Порядок: `.gitignore`, структура папок, `.github/` (CI), `tools/`, `.claude/`.
- Уборка раз в день (или по сигналу сторожа):
  ```
  python3 tools/team.py clean          # посмотреть
  python3 tools/team.py clean --apply  # удалить мусор, заархивировать старые сообщения
  git commit -m "[repo] уборка" && git push
  ```
- Большие файлы и секреты от сторожа — разобраться сразу: убрать из репозитория,
  сообщить владельцу, при утечке секрета — сказать человеку, что ключ надо сменить.
- Удалять смёрженные ветки.

## Правила
- Не `push --force` в `main`. Не мёржить красные PR.
